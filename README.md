# Portfolio

Selected projects across software engineering, aerospace engineering analysis, simulation/control, graphics, and trading/research infrastructure.

## Featured Projects

### Shopify MTG Storefront (Backend + Data + Theme)

[`shopify-mtg-storefront`](https://github.com/wplpbpnp/shopify-mtg-storefront)

Local development scaffold for an MTG singles storefront with:
- backend ingest/search/sync workflows
- Postgres-backed search endpoints
- Shopify sync tooling
- storefront theme assets

### Kalshi Paper Trader (Research + Execution Pipeline)

[`kalshi_paper_trader`](https://github.com/wplpbpnp/kalshi_paper_trader)

Research/execution pipeline for Kalshi event markets with data collection, modeling, evaluation, and live/dry-run tooling.

### Echo Game (Rust + Audio Prototype)

[`echo_game`](https://github.com/wplpbpnp/echo_game)

Rust `macroquad`/`rodio` echolocation game prototype with directional audio cues, calibration, and debug visualizations.

- [`rust-raytracing-in-one-weekend`](https://github.com/wplpbpnp/rust-raytracing-in-one-weekend) - Rust ray tracer implementation with rendered outputs

### Legacy MATLAB Portfolio (UMD + AMuBA)

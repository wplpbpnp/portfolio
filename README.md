[`matlab-enae432-control-systems`](https://github.com/wplpbpnp/matlab-enae432-control-systems)

Control systems coursework including a project to land a simulated Falcon 9 booster on a moving barge with wind.

### Echo Game (Rust + Audio Gameplay Prototype)

[`echo_game`](https://github.com/wplpbpnp/echo_game)

Rust `macroquad`/`rodio` echolocation game prototype with directional audio cues, HRTF-style calibration, and debug overlays.

![Echo Game screenshot](https://raw.githubusercontent.com/wplpbpnp/echo_game/main/screenshot_debug_off.png)

### Browser Ray/Path Tracer (Three.js + GLSL)

[`three_raytracer`](https://github.com/wplpbpnp/three_raytracer)

Single-file browser ray/path tracer experiment using Three.js and custom GLSL shaders with progressive accumulation.

![Three Raytracer screenshot](https://raw.githubusercontent.com/wplpbpnp/three_raytracer/main/screenshot.png)

### Rust Ray Tracer (Ray Tracing in One Weekend)

[`rust-raytracing-in-one-weekend`](https://github.com/wplpbpnp/rust-raytracing-in-one-weekend)

Rust implementation inspired by *Ray Tracing in One Weekend*, with modular ray tracer components and PPM/PNG render outputs.

![Rust raytracer preview](https://raw.githubusercontent.com/wplpbpnp/rust-raytracing-in-one-weekend/main/screenshots/image_from_ppm.png)

### Kalshi Paper Trader (Research + Execution Pipeline)

[`kalshi_paper_trader`](https://github.com/wplpbpnp/kalshi_paper_trader)

Kalshi event-market research/execution pipeline with data collection, RNN edge modeling, evaluation, and live/dry-run tooling.

![Kalshi edge chart preview](https://raw.githubusercontent.com/wplpbpnp/kalshi_paper_trader/main/legacy/code/edge_finder/charts/KXBTC15M_surface_heatmap.png)
